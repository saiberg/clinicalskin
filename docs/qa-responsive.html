Las media queries del sitio responden al ancho del iframe: 360/400 = móvil (≤720), 740 = tablet (≤1024), 1100 = escritorio. Debajo de cada ancho aparece ✓ o ✗: revisa desbordamiento horizontal, altura del header (120px), wordmark visible y que las etiquetas del hero no tapen la tarjeta. Si algo se ve desactualizado, marca Disable cache en DevTools → Network y recarga.
